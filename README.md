# WHAT I WANT YOU TO KNOW

A guided legacy book for parents and grandparents, written in their own hand, speaking directly to
the people who will one day read it. Built as a commercial Amazon KDP product.

**Emotional promise:** Write it while you're here. Keep it forever.

## Working rules

- Nothing in this repo may read as AI-generated. Every prompt is read aloud before it stays.
- No two consecutive prompts share a sentence structure.
- Permission to skip is designed in, not disclaimed.
- Death is present but never the topic. No "before it's too late." No clock.
- No bestseller or "number one" claims in any product copy until Amazon's badge is live.
- The repository name never appears in product-facing text.
