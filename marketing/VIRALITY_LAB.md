# Virality Lab

A prioritization framework, not a prediction. Each promising idea is scored 1 to 10 on ten
dimensions. Production cost is scored inverted (10 = nearly free). The total is a ranking tool for
deciding what to make this week. Nothing here is a claim that an idea will go viral.

Scoring questions:

| Dimension | The question |
|---|---|
| Hook | Does the first line stop a thumb in under a second? |
| Curiosity | Does it open a loop the viewer has to close? |
| Emotion | Does it make the viewer feel something specific, not generic? |
| Shareability | Would someone send it to a parent or sibling with no comment? |
| Comment | Does it ask a real question people want to answer? |
| Save | Would someone keep it for later use? |
| Visual | Is there a frame worth looking at? |
| Series | Can it run 50 times without repeating itself? |
| Book | Is the book the natural next step, without being the subject? |
| Cost (inverted) | 10 = a text card; 1 = a shoot with releases and edits |

## Re-scoring rule

After a concept posts, replace the guess with a result in `WEEKLY_MARKETING.md` and mark the row
here with the actual share and comment counts. Scores drift toward what the audience did, not what
we thought.
